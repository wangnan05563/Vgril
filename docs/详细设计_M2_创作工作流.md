## 0. M2 与 M0/M1 的衔接契约

M2 在 M0（基座 + 合规拦截器 + SafetyFilter）+ M1（记忆/人设情绪/大模型/语音/数字人）之上构建，并遵守已在设计包中锁定的硬约束：

1. **隐私边界（D1）**：创作产物（字幕轨迹、录屏视频、片段、主题包、场景配置、记忆导出）**全部本地存储**；任何"分享/导出"均为用户**显式触发**，绝不自动上传、不携带记忆/情绪/关系上下文出境。记忆导出属用户自有数据备份，经 `trainingOptIn` 硬锁确认不参与训练（REQ-COMP-05）。
2. **内容安全（D5）**：分享/导出前的成品**必须经过 `SafetyFilter.screen`**（D3/D5 延伸）——避免把底线词或危机相关内容渲染进字幕/视频/片段后扩散。命中则拦截该片段分享，提示用户。
3. **危机耦合（D3）**：录屏/片段若捕获到危机干预弹窗，导出时自动打码或跳过该片段；常驻资源入口不依赖创作模块存在。
4. **SSRF（D2）**：创作工作流为纯前端本地能力（MediaRecorder / Canvas / 文件读写），**不新增任何 `/api/*` 出站端点**；若后续需本地 ffmpeg，走固定二进制路径（非用户可控 URL），不沿用旧 `x-llm-endpoint` 模式。
5. **AI 标识（REQ-COMP-01）**：数字人/语音输出的"由 AI 生成，非真人"水印随画面一并被录屏捕获（不可关闭），即录屏产物天然带标识。

## 1. 范围与依赖

M2 交付六个能力（字幕/录屏/片段/场景/主题/记忆库），覆盖：

## 3. 字幕系统 `Studio.subtitle`（REQ-CT-01）

### 3.1 轨迹数据结构（新增 IndexedDB `captions` store）

```jsonc
// IndexedDB store: captions (keyPath:'id', index:'sessionId','speaker','startMs')
{
  "id": "uuid",
  "sessionId": "session-uuid",         // 关联 M0 session store
  "startMs": 1200,                      // 相对会话起点的毫秒
  "endMs": 4800,
  "speaker": "user" | "xiaoya",
  "text": "小雅今天也想你了哦",
  "emotionTag?": "affection",           // 可选：取自 PersonaEngine，便于片段检索
  "screened": true                      // 入库前已经 SafetyFilter.screen（D5）
}
```

### 3.2 实时维护 `pushCue(turn)`

```
pushCue({speaker, text, emotionTag?}):
  screened = SafetyFilter.screen(text)       // 入库即滤（D5）
  if !screened.pass: return                  // 底线词不进字幕
  cue = {id:uuid(), sessionId:currentSession,
         startMs: now()-sessionStart, endMs:null,
         speaker, text:screened.text, emotionTag, screened:true}
  activeCue = cue; idb.put('captions', cue)
  renderLive(cue)                            // 聊天区下方实时字幕条
```

- **写入时机**：`LLMAdapter.respond` 流式 yield 完成一句即 `pushCue('xiaoya', chunk)`；用户发送即 `pushCue('user', msg)`。
- **结束**：句子边界（标点 / 静音检测）落 `endMs`。

### 3.3 多模板导出 `export(format, templateId)`

```
export(format='vtt', templateId='default'):
  cues = idb.getAllByIndex('captions','sessionId', currentSession)
  tpl  = loadTemplate(templateId)            // 读 subtitle_templates/<id>.json
  body = render(cues, tpl, format)           // vtt/srt/txt 差异见下
  blob = new Blob([body], {type:mime(format)})
  download(blob, `xiaoya_${sessionId}.${ext(format)}`)   // 本地下载，不上传（D1）
```

**格式差异**：
- `.vtt`：`WEBVTT\n\n00:00:01.200 --> 00:00:04.800\n小雅今天也想你了哦\n`
- `.srt`：`1\n00:00:01,200 --> 00:00:04,800\n小雅今天也想你了哦\n`
- `.txt`：纯文本对话稿（无时间轴，便于校对/记忆回顾）。

**模板字段** `@assets/data/subtitle_templates/default.json`：
```jsonc
{
  "id":"default", "name":"默认",
  "cueBox":{"position":"bottom-center","maxWidth":"80%","bg":"rgba(0,0,0,.0)"},
  "font":{"size":"1.6vw","color":"#FFFFFF","stroke":"#000","strokeWidth":2},
  "dualTrack":false
}
```
模板仅控制渲染样式（位置/字体/描边/双行），不影响文本安全（文本已由 §3.2 过滤）。

## 4. 录屏烧录 `Studio.recordAndBurn`（REQ-CT-02）

### 4.1 目标
把现状手改 `record_burn.ps1` 升级为**图形化一键**：选源 → 开始 → 自动把实时字幕**烧录进画面** → 停止 → 本地成片。全程纯前端（Canvas 合成 + MediaRecorder），不依赖服务端或外部 ffmpeg（D2）。

### 4.2 流程 `recordAndBurn(opts)`

```
recordAndBurn(opts={templateId:'default', withSubtitle:true, withMic:false}):
  // 1) 取屏（用户授权）
  stream = await navigator.mediaDevices.getDisplayMedia({video:{frameRate:30}, audio:true})
  if opts.withMic:
      mic = await navigator.mediaDevices.getUserMedia({audio:true})
      stream = mixAudio(stream, mic)              // 系统音 + 麦克风混音
  // 2) Canvas 合成（烧录字幕）
  canvas = createCanvas(stream.videoWidth, stream.videoHeight)
  ctx = canvas.getContext('2d')
  composer = new SubtitleCompositor(canvas, loadTemplate(opts.templateId))
  // 3) 录制
  canvasStream = canvas.captureStream(30)
  recorder = new MediaRecorder(canvasStream, {mimeType:'video/webm;codecs=vp9', videoBitsPerSecond: cfg.studio.recorderBitrate||8e6})
  recorder.ondataavailable = e => chunks.push(e.data)
  recorder.start()
  composer.loop(stream, activeCue)               // 每帧：画视频 + 画字幕
  // 4) 停止（用户在 UI 点停）
  await waitStop()
  recorder.stop()
  blob = new Blob(chunks, {type:'video/webm'})
  download(blob, `xiaoya_record_${ts()}.webm`)   // 本地成片（D1）
```

- **烧录原理**：`SubtitleCompositor.loop` 每 rAF 把视频帧 `drawImage` 到 canvas，再按模板把 `activeCue.text` 画到底部（带描边）。字幕随画面一并编码进视频——无需 ffmpeg 后处理，离线可用。
- **AI 标识自动带出（REQ-COMP-01）**：数字人/语音输出区的 `renderAIBadge()` 水印在屏幕上，被 `getDisplayMedia` 捕获，成片天然带"由 AI 生成，非真人"。
- **危机打码（D3）**：若录制期间 `ComplianceGate.onCrisis` 触发，记录 `crisisWindow[]`；导出时在对应时间段叠加黑场/模糊，避免危机弹窗内容扩散。

### 4.3 `record_burn.ps1` 处置
保留为底层引擎（兼容需要硬烧录 `.srt` 到已有 mp4 的高级用户），但默认入口改为 `Studio.recordAndBurn` 的图形化流程；文档注明两者并存。

## 5. 片段精选 `Studio.clipBest`（REQ-CT-03）

### 5.1 峰值扫描 `scanPeaks(cues, emotionLog)`

```
scanPeaks(cues, emotionLog, topK=3):
  // 以"情绪强度"给每个 cue 打分：高 arousal / affection 峰值 / jealousy 尖刺 = 有趣瞬间
  scored = cues.map(c => {
     e = nearestEmotion(emotionLog, c.startMs)
     s = e.arousal*0.4 + e.affection*0.3 + e.jealousy*0.3
     return {cue:c, s}
  })
  scored.sort((a,b)=>b.s-a.s)
  peaks = scored.slice(0, topK)
  return peaks   // 返回时间窗 [startMs, endMs]，用于切视频或生成卡片
```

### 5.2 产出两种形态
- **有录屏**：`cutVideo(peaks)` —— 用 `MediaSource`/`<video>` 选区 + Canvas 重编码导出短视频片段（webm）；若无成片则提示"先录屏再精选"。
- **无录屏（轻量）**：`makeCard(peak)` —— 生成"名场面卡"：背景取当前主题色 + cue 文本 + 情绪标签 + 小雅头像（CSS 滤镜着色），导出 PNG（本地，D1）。

### 5.3 分享前安检（D5/D3）
```
share(artifact):
  screened = SafetyFilter.screen(artifact.textContent)   // 文本先滤
  if !screened.pass: UI.toast("该片段含不适内容，已阻止分享"); return
  if artifact.overlaps(crisisWindow): UI.toast("含危机干预时段，已跳过"); return
  // 显式下载/复制，绝不自动上传（D1）；不内置任何社交 SDK（隐私）
  download(artifact.blob)
```
- **边界**：分享是用户主动动作，成品文件落在本地；如需发到社交平台由用户自行操作，小雅不集成上传通道（避免把陪伴内容泄露到第三方）。

### 6.2 切换 `applyScene(id)`

```
applyScene(id):
  scene = loadScene(id)
  if scene.unlockLevel and relation.level < scene.unlockLevel:
      UI.toast("该场景需亲密度等级 "+scene.unlockLevel+" 解锁"); return

  setBackground(scene.background)                   // UI 背景
```

### 7.2 应用 `applyTheme(pkgOrId)`

```
applyTheme(pkg):
  // 内置：直接取 themes/<id>.json；导入：用户 file input 选 .json/.zip → 校验 → 解包
  validateTheme(pkg)                                // 字段白名单，防注入
  setCSSVars(pkg.colors)                            // :root 自定义属性
  document.documentElement.style.setProperty('--accent', pkg.colors.accent) ...
  if pkg.avatarFilter: xiaoyaImg.style.filter = pkg.avatarFilter
  if pkg.bgm: BGM.play(pkg.bgm)
  saveConfig({studio:{theme:pkg.id}})               // 走 /api/config，服务端持久化
```

- **导入安全**：主题包仅允许 `colors / bgm / avatarFilter` 字段；`avatarFilter` 限定为已知 CSS filter 函数白名单（非任意 JS/CSS 注入），防 XSS（内容安全延伸）。
- **默认 4 套**：继承现有皮肤（樱粉/午夜蓝/像素/黑白），与既有"4 套皮肤主题"能力对齐。

## 8. 记忆库可视化 `Studio.memoryPanel`（REQ-FUN-03）

复用 M1 `MemoryStore.list/update/remove`（§3.4），提供 UI 面板：

```
renderMemoryPanel(filter?):
  items = MemoryStore.list(filter)                 // 按 topic 分组
  for it in items:
      renderRow(it)                                // 文本 + 主题 + importance 进度条 + 时间
      bindEdit(it.id)   -> MemoryStore.update(it.id, patch)   // 二次确认
      bindDelete(it.id) -> confirmDialog -> MemoryStore.remove(it.id)
  bindExport() -> exportMemoryJSON()               // 用户备份，本地下载（D1）
```

- **导出记忆**：`exportMemoryJSON` 把 `memory` store 全量导出为 JSON（用户自有数据），经 `trainingOptIn` 硬锁确认"不用于训练"（REQ-COMP-05）；不自动上传。
- **隐私**：面板只读本地 IndexedDB，无网络请求。

## 11. 验收用例（映射 REQ-CT/FUN）

| REQ | 验收用例 | 预期 |
|---|---|---|
| CT-01 | 对话中观察聊天区下方 | 实时字幕随每一句出现；切换模板后导出 `.vtt` 样式位置改变 |
| CT-01 | 导出 `.srt`/`.txt` | 时间轴格式正确；`.txt` 为纯对话稿；文本不含底线词（入库已滤） |
| CT-02 | 点"一键录屏"→选屏→停止 | 本地生成 webm；播放可见烧录字幕与"由 AI 生成"水印；全程无网络请求 |
| CT-02 | 录制中触发危机弹窗 | 导出成片对应时段被打码/模糊（crisisWindow 生效） |
| CT-03 | 长会话后"精选片段" | 返回 Top3 情绪峰值片段；无录屏时生成 PNG 名场面卡 |
| CT-03 | 对含底线词片段点分享 | 被 `SafetyFilter` 拦截，提示"已阻止分享"，不下载 |

## 12. 风险与实现注意

| 项 | 说明 | 处置 |
|---|---|---|
| 录屏权限 | `getDisplayMedia` 需 HTTPS 或 localhost | 文档注明；打包壳为 localhost，满足 |
| 烧录性能 | Canvas 每帧 drawImage + 字幕，4K 屏可能掉帧 | 限制合成分辨率 ≤1080p；降帧率到 30 |
| 浏览器兼容 | Firefox/Safari 对 `captureStream`/编码支持不一 | Chromium 内核优先（含打包壳）；其他内核降级提示 |
| 字幕时间精度 | 句子边界依赖标点/静音检测 | fallback：固定句长（如 >4s 强制断句） |
| 主题注入 | 导入包可能夹带恶意 CSS/JS | `validateTheme` 字段白名单 + filter 函数白名单，禁 `url()`/表达式求值 |
| 片段分享泄露 | 陪伴内容外传风险 | 无内置上传 SDK；分享=本地下载；文本安检 + 危机跳过（D1/D5/D3） |
| 记忆导出合规 | 导出记忆可能被误用 | `trainingOptIn` 硬锁确认；导出即用户明示动作 |
