## 二、根因（为什么"未达预期"）

### 🔴 P0-1　运行中的 exe 出站走失效代理 → 所有云端 API 超时
- 干净环境（无代理）启动的服务端 → 直连 SiliconFlow **正常返回**（带真实 key 直连 5.76s 拿到有效回复，key/模型/网络均 OK）。
- 运行中的实例 `/api/llm` → **502（30s 超时）**；`api.heygen.com` 直连 **16s 超时**。
- 结论：该 exe 的启动环境里残留了**失效的 `HTTPS_PROXY`**，使其所有出站调用都走死代理而超时。
- 表现：大模型智能回复出不来（每次都超时回退本地傲娇引擎）；数字人更不可能成功。

### 🔴 P0-2　HeyGen 本机网络不可达（区域/ISP 封锁）
- `api.heygen.com` 实测 16s 超时，本机直连不通。当前 `dhProvider=heygen` 启用，每次说话都会先等 HeyGen ~30s 超时再回退本地 SVG 头像 → "数字人出不来/卡顿"。

### 🟡 P1-1　配置副本分裂
- 根目录 `xiaoya_config.json`（dummy+deepseek）与 `dist\xiaoya_config.json`（真实密钥）不一致。
- 风险：若改用 `python server.py`（根目录）或根目录 exe 重启，会丢失已配的真实 key、回退 dummy/deepseek。

### 🟢 P2-1　BGM 素材缺失
