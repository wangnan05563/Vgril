Codex-QQ-Skin 使用说明

赛博女友「小雅」· 数字人交互网页 · 零依赖双击运行

数字人形象 语音对话 大模型接入 字幕录屏

1这是什么

Codex-QQ-Skin 是一个单文件网页应用，把「固定长相的数字人女友小雅」做成了可交互的桌面伴侣：

  • 左侧：功能导航（聊天 / 记忆库 / 设置 / 数字人状态）。
  • 中间：聊天区，小雅有傲娇、爱吃醋、会委屈的人设，等久了会闹小脾气。
  • 右侧：小雅人像，说话时会有呼吸 / 口型脉冲动画，可切换为数字人视频。
  • 底部：圆形语音按钮，支持语音输入（STT）与语音播报（TTS）。

未配置任何密钥也能直接玩：默认走本地人设引擎 + 浏览器语音合成。想要「真人级口型」再接数字人 API 即可。

2三步跑起来

① 拿发布包

打开 dist/ 文件夹，里面是完整发布包：CodexQQSkin.exe、index.html、xiaoya.png 等。

② 双击运行

双击 CodexQQSkin.exe，它会自动在 127.0.0.1:8080 起服务并打开浏览器，无需安装任何依赖。

③ 开始聊天

浏览器打开后即进入小雅主页，直接打字或点圆形按钮语音对话。

没有 exe？也可以双击 script/start.bat：它会优先用 exe，否则自动用本机 Python 启动 server.py。macOS / Linux 用 script/start.sh。

3功能一览

小雅人设引擎

傲娇、敏感、爱吃醋；你表白她会脸红，冷落她久了她会委屈开场，偶尔闹小脾气。纯本地关键词 + 情绪状态机，离线可用。

语音播报（TTS）

用浏览器 SpeechSynthesis 朗读小雅的回复，支持语速 / 音调调节。中文语音取决于系统已安装的语言包。

语音输入（STT）

点底部圆形按钮说话，浏览器识别为中文文本发给小雅。需要 Chrome / Edge 且授权麦克风。

记忆库

对话自动存进浏览器 localStorage，可随时打开弹窗查看历史，也能一键清空。

实时字幕 + 导出

小雅说话时底部实时显示字幕，可导出 .vtt / .srt 字幕文件，方便后期录屏烧录。

设置面板

4 套皮肤主题、TTS 语速 / 音调滑块、上传背景音乐（BGM）、数字人高级配置，全部可视化。

4接入真实大模型（可选）

默认小雅是「本地人设引擎」。想让她更聪明、能聊任意话题，在设置面板里填写大模型配置即可（OpenAI / DeepSeek 兼容接口）：

  • enabled：打开开关
  • endpoint：接口地址，如 https://api.deepseek.com/v1/chat/completions
  • apiKey：你的密钥
  • model：模型名，如 deepseek-chat
  • system：人设提示词（可保留小雅的傲娇性格）

填好后会优先走真实大模型；调用失败自动回退本地引擎，不会「哑火」。

5接入数字人视频（可选）

想让小雅「真人级口型 + 表情」，在设置面板配置数字人，或在服务端 keys.json 放密钥：

HeyGen

# dist/keys.json
{
  "heygen": "sk-你的-heygen-key"
}

面板填：服务商=HeyGen、Avatar ID、Voice ID、API Key。

腾讯智影（数智人）

# dist/keys.json
{
  "zhiying_secret_id": "AKID...",
  "zhiying_secret_key": "...."
}

密钥留在服务端由 server.py 做 TC3 签名，规避浏览器 CORS 与明文暴露。

未配置时，右侧人像用 CSS 呼吸 / 口型脉冲动画「假装说话」，体验不中断；配置后自动切换为真实数字人视频。

6录屏并烧录字幕

想做「小雅开口说话」的视频，流程如下：

  1. 在网页里打开字幕条，和小雅对话（字幕实时滚动）。
  2. 点字幕区的「导出」拿到 .srt 或 .vtt。
  3. 运行 script/record_burn.ps1：首次会自动装 ffmpeg，用 gdigrab 录全屏，并把字幕烧录进视频（微软雅黑 / 白字描边 / 底部居中）。
# PowerShell（需以能录屏的权限运行）
powershell -ExecutionPolicy Bypass -File script/record_burn.ps1

背景音乐「御姐进行曲」在设置面板上传 BGM 即可随对话播放。

7常见问题

现象原因 / 解决
双击 exe 没反应 / 被拦截Windows 可能误报，放行或允许运行；确保 dist/ 内文件齐全。
语音播报没声音系统未装中文语音包；去系统设置添加「中文（简体）语音」，或换 Chrome / Edge。
语音输入不工作需用 Chrome / Edge，且首次要授权麦克风；部分浏览器不支持 Web Speech STT。
端口 8080 被占用关闭占用程序，或修改 server.py 里的 PORT 后重新打包。
数字人视频不出检查 keys.json 密钥是否正确、网络是否可达服务商接口。
