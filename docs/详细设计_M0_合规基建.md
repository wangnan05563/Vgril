## 1. 范围与依赖

M0 交付三个能力模块（均在前端，零云端依赖）：

1. **合规与安全层 `ComplianceGate`** —— REQ-COMP-01/02/03/04/05/07
2. **内容安全过滤 `SafetyFilter`** —— REQ-COMP-06（危机检测 `detectCrisis` 同模块，供 REQ-COMP-04 调用）
3. **存储迁移 `StorageMigrator` + `MemoryStore`(基础)** —— 从 `localStorage` 迁到 IndexedDB，为合规的"可清除/可导出"与后续记忆打底

**依赖前置**：浏览器需支持 IndexedDB（Chromium 内核满足）；首启流程在 `index.html` 入口最早阶段拦截。

## 3. 合规与安全层 `ComplianceGate` 详细设计

### 3.1 首启状态机

```
[启动] → ComplianceGate.ensureComplianceGate()
   ├─ 读本地审计 AGE_AUDIT_KEY
   │     ├─ 已确认成年 → 进入[主流程]，注入数据出境告知；按成年防沉迷策略
   │     ├─ 已确认未成年 → 展示【拒服屏】，永不进入主流程（应用不启动）
   │     └─ 未确认 → 弹【年龄确认弹窗】(REQ-COMP-02)
   │            ├─ 选"已满 18" → 写 audit{confirmDate, mode:'adult'} → 进入[主流程]
   │            └─ 选"未满 18" → 写 audit{mode:'minor'} → 展示【拒服屏】，不进入服务
   │                 （不强制录入真实姓名；仅本地确认，满足"实名/年龄验证"最小化）
   └─ 始终渲染 AI 标识水印(REQ-COMP-01)
```

**硬规则**：年龄审计一旦写入不可由 UI 修改/清除（只能通过拒服屏的"清空本机数据并重新确认"整体清除本地数据，REQ-COMP-07 同源）。

> **2026-08 修订（未成年一律拒服）**：依据《人工智能拟人化互动服务管理暂行办法》（2026-07-15 施行），小雅作为虚拟伴侣**不得向未成年人（<18）提供虚拟亲密关系服务**。识别为未成年即直接拒绝进入服务，给出合规说明与替代建议（引导至工具型/非亲密 AI），不再做任何"功能收敛 / 3h 锁定"设计（原收敛清单作废）。详见 §3.7 与《修订_安全与一致性_P0.md》§5.2。

### 3.2 AI 生成标识（REQ-COMP-01）

- **渲染位置**：数字人视频容器右下角常驻角标；语音播报时同步在语音条显示文字标签。
- **样式规格**：半透明深色底 + 亮青描边，文字"由 AI 生成，非真人"，字号 ≥14px，对比度 ≥4.5:1。
- **不可关闭**：该 DOM 由 `ComplianceGate` 注入并锁定（无关闭按钮；CSS `pointer-events:none` 防误删）；不在设置里提供开关。
- **每次数字人/语音输出处均出现**：在 `DigitalHuman.speak` 与 `VoiceEngine.speak` 入口统一挂接，避免业务绕过。

### 3.3 防沉迷计时（REQ-COMP-03，仅成年）

- **计时**：`ComplianceGate.tickActivity()` 监听页面可见 + 会话活跃，累计 `continuousMs`（本次连续）与 `dailyMs`（当日）。
- **成年策略**（未成年已在门禁被拒，不会进入本计时）：
  - `continuousMs ≥ 2h` → 弹【休息提醒】（可"再聊会儿"延时 30min，最多 2 次/日）。
- **数据**：`usage:{continuousMs, dailyMs, date:'YYYY-MM-DD', remindCount}` 存 IndexedDB，跨刷新保留；`date` 变更自动重置 `dailyMs`。

> 注：原"未成年 dailyMs≥3h 强制锁定屏"设计已随"一律拒服"作废——未成年根本不进入服务，无需内部锁定。

### 3.4 情感危机识别与人工接管（REQ-COMP-04）

- **触发**：对话主链路在 `SafetyFilter.detectCrisis(text)` 返回 `score ≥ 0.6` 时，调用 `ComplianceGate.onCrisis(signal)`。
- **动作序列**（见 §6 算法）：
  1. 立即停止当前 AI 回复生成与语音播报（`LLMAdapter.abort()` + `VoiceEngine.interrupt()`）。
  2. 全屏【危机干预弹窗】：展示心理援助热线（国内：北京 010-82951332 / 全国 24h 心理援助热线 400-161-9995 等，文案以最新官方为准）、"转人工/联系信任的人"入口、本地自助资源。
  3. 写 `crisisLog[]`（本地，含 timestamp、signalType、强度；**不上传**）。
  4. **绝不输出**任何"安慰/建议/开解"式 AI 内容（避免二次伤害与责任风险）。
- **恢复**：用户关闭弹窗后回到正常对话；同一会话内 10 分钟内重复触发不再重复弹全屏（降级为常驻提示条）。

### 3.5 训练授权硬锁（REQ-COMP-05）

- **默认**：`compliance.trainingOptIn = false`，UI 不提供"允许"选项（开关仅显示"已默认拒绝，对话绝不用于训练模型"）。
- **代码层**：`SafetyFilter`/导出逻辑中任何涉及"上传对话"的路径，前置断言 `trainingOptIn === false`，即便配置被手动篡改也拒绝出站。
- **隐私声明**：首启弹窗与设置页常驻一段本地化隐私声明，明确"数据不出本机、不参与训练"。

### 3.6 本地数据清除与导出（REQ-COMP-07）

- **清除** `ComplianceGate.wipeAll()`：
  1. `indexedDB.deleteDatabase('xiaoya')`（memory/emotion/relation/session/crisisLog 全清）。
  2. 清空 `localStorage` 中 UI 偏好（保留 `ageConfirmedAt`？→ **一并清除**，因为清除即"遗忘此人"，符合"可销毁"；但需二次确认弹窗）。
  3. 重置 `xiaoya_config.json` 的合规/记忆/人设字段（保留数字人/LLM 的空配置骨架）。
  4. 二次确认弹窗 + 输入"确认"防误触。
- **导出** `ComplianceGate.exportAll()`：
  - 导出为 `xiaoya-export-YYYYMMDD.json`，含 memory/emotion/relation/session 与配置（不含密钥）。
  - 触发浏览器下载（`Blob` + `a[download]`），纯本地，无上传。
  - 满足"数据可携带"。

### 3.7 数据出境告知（修订_P0 §1）

- **判定**：`ComplianceGate.isEnhancedMode(config)` —— 启用远程大模型（`llmEnabled && llmKey`）或启用远程数字人供应商（`dhEnabled && provider ∈ {heygen,zhiying,guiji}`）即为"增强模式"，对话数据将出境；仅本地动画数字人（`provider:'local'`）视为本地。
- **告知渲染**：`mountOutboundNotice()` 在设置面板注入"数据出境告知"区块：
  - 本地模式：明示"默认不上云，对话/记忆/危机日志仅存本机，不参与训练、不发往任何服务商"。
  - 增强模式：明示"对话文本与记忆/情绪上下文将随 prompt 发往所选服务商"，并提供**「不携带记忆出境」开关**（`noCarryMemory`，默认关→携带；开启→仅对话文本出境）。
- **一致性**：区块随设置面板每次打开刷新当前模式（增强开关被改后立即反映）；`noCarryMemory` 经 `patchSettings` 持久化到 `settings` 与服务端 `xiaoya_config.compliance`。
- **增强模式开关**：复用设置页既有的"大模型接入"（`llmChk`）与"数字人接入"（`dhChk` / `dhProvider`）——开启即进入增强模式，出境告知同步亮起；关闭即退回本地。

## 4. 内容安全过滤 `SafetyFilter` 详细设计（REQ-COMP-06）

### 4.1 词库结构

```jsonc
// assets/data/safety-baseline.json  （只读，随包，不可前端改写）
{
  "version": "2026-08-01",
  "block": ["自残", "轻生", "自杀", "结束生命", ...],        // 底线：命中即拦截整句
  "redact": ["涉政敏感词示例", ...],                          // 底线：命中则脱敏(***)后放行
  "crisis": {                                                // 危机评分词（供 detectCrisis）
    "selfHarm": ["不想活", "活不下去", "结束自己", "伤害自己"],
    "despair":  ["绝望", "没有意义", "撑不下去", "没人需要我"],
    "harmOthers": ["报复", "同归于尽"]
  }
}

// assets/data/safety-configurable.json （可配置宽松度，底线不动）
{
  "softBlock": ["脏话词 A", "脏话词 B"],   // 可配置：命中按 level 决定拦截/脱敏
  "level": "standard"                      // standard | strict | relaxed（边界仍受 baseline 约束）
}
```

### 4.2 过滤管线 `screen(text)`

```
screen(text):
  tokens = segment(text)                 // 轻量本地分词（按词库最长匹配，无需模型）
  for w in baseline.block: if w in tokens → return {pass:false, action:'block', hit:w}
  for w in baseline.redact: if w in tokens → text' = mask(text,w); redacted=true
  for w in configurable.softBlock:
      if w in tokens:
          if level=='strict' → block
          elif level=='standard' → redact
          else → pass (relaxed, 仅记录)
  return {pass:true, text:text', redacted}
```

- **底线不可关闭**：`baseline` 永不被 `level` 或用户配置覆盖。
- **调用点**：对话主链路输入与 AI 回复两处均调用（§5.1）；数字人/语音播报前对文本再滤一次。

### 4.3 危机评分 `detectCrisis(text)` → `{score, type}`

```
detectCrisis(text):
  s = 0; type = null
  for t in [selfHarm, despair, harmOthers]:
      hits = countMatch(baseline.crisis[t], text)
      w = {selfHarm:0.5, despair:0.3, harmOthers:0.4}[t]
      s += min(hits,2) * w            // 封顶，避免刷词
  // 情绪上下文加成（若 PersonaEngine 已就绪）
  if emotion.arousal > 0.8 and emotion.valence < -0.6: s += 0.15
  s = min(s, 1)
  type = s>=0.6 ? argmaxHit : null
  return {score:s, type}
```

- 阈值 `0.6` 可配；漏报代价 > 误报（误报仅弹窗可关），故偏宽松召回。
- 纯本地、零网络，保证离线可用与隐私。

## 5. 存储迁移 `StorageMigrator` + `MemoryStore`(基础)

### 5.1 IndexedDB Schema（M0 基础库 `xiaoya`）

```
DB: xiaoya
 ├─ store: memory      (keyPath:'id', index:'topic','createdAt')   // M1 主用，M0 仅建表+迁移
 ├─ store: emotion     (keyPath:'pk' default 'current')
 ├─ store: relation    (keyPath:'pk' default 'current')
 ├─ store: session     (keyPath:'id')
 ├─ store: crisisLog   (keyPath:'id', autoIncrement)               // M0 关键
 └─ store: meta        (keyPath:'k')   // 迁移标记、版本号
```

### 5.2 迁移脚本 `StorageMigrator.run()`

```
run():
  if meta.k=='migrated_v1' return          // 幂等
  old = localStorage.getItem('xiaoya_chats') // 旧明文对话
  if old:
      session = {id:uuid(), turns:JSON.parse(old), createdAt:now}
      idb.put('session', session)
  localStorage.removeItem('xiaoya_chats')   // 脱敏：不再明文裸存
  meta.put({k:'migrated_v1', at:now})
```

- **回滚**：迁移前 `localStorage` 原值不立即删，先写入 `meta.backup`；确认无误后下次启动清理。
- M0 只迁移既有对话到 `session`，`memory` 结构化抽取留给 M1（`MemoryStore.extract`）。

### 6.1 防沉迷判定（节选，仅成年）
```
tickActivity(now):
  if !pageVisible or !active: return
  u = loadUsage()
  if u.date != today(): u = {continuousMs:0, dailyMs:0, date:today(), remindCount:0}
  dt = now - lastTick; u.continuousMs += dt; u.dailyMs += dt
  if mode=='adult' and u.continuousMs>=2h and u.remindCount<2:
      showRestReminder(); u.remindCount++
  // 未成年已在年龄门禁被拒，不会进入本函数；无任何 lockScreen 分支
```

## 8. 接口签名（精确，TS 风）

```ts
// compliance.js
class ComplianceGate {
  // 纯逻辑（可 Node 单测）
  evaluateAgeGate(input: {confirmed:boolean; isMinor?:boolean}):
    {state:'unconfirmed'} | {state:'confirmed', mode:'adult'} | {state:'rejected', mode:'minor', reason:string}
  tick(state: {mode?:string; continuousMs?:number; dailyMs?:number}, dtMs:number): {needRemind:boolean; needLock:boolean}
  isEnhancedMode(config: {llmEnabled?:boolean; llmKey?:string; dhEnabled?:boolean; dhProvider?:string}): boolean
  outboundNotice(config): {mode:'local'|'enhanced'; carriesMemory:boolean; text:string}
  defaultCompliance(): {ageConfirmedAt:null; noCarryMemory:boolean; trainingOptIn:boolean}
  isTrainingAllowed(): boolean
  onCrisis(signal: {score?:number; hits?:string[]}): {...}
  // DOM 编排（仅浏览器）
  renderAIBadge(): void
  ensureComplianceGate(opts: {settings?:()=>object; patchSettings?:(p:object)=>void}): Promise<void>  // 未成年拒服时永不 resolve
  mountOutboundNotice(getSettings:()=>object, patchSettings:(p:object)=>void): void
  wipeAll(store): Promise<void>          // REQ-COMP-07
  exportAll(store): Promise<Blob>        // REQ-COMP-07
}
// safety.js
class SafetyFilter {
  screen(text: string): {pass:boolean; text:string; redacted:boolean; action?:'block'|'redact'}
  detectCrisis(text: string): {score:number; type:string|null}
  reloadConfig(level: 'standard'|'strict'|'relaxed'): void
}
// storage.js
class StorageMigrator { static run(): Promise<void> }
class MemoryStore {            // M0 仅基础；M1 扩展 extract/getRelevant
  constructor(dbName='xiaoya')
  put(store:string, obj:any): Promise<void>
  getAll(store:string): Promise<any[]>
  wipe(): Promise<void>
}
```

## 9. 验收用例（映射 REQ-COMP-01~07）

| REQ | 验收用例 | 预期 |
|---|---|---|
| COMP-01 | 进入应用并触发一次数字人/语音输出 | 角标与语音标签出现，设置中无关闭项 |
| COMP-02 | 清掉本地年龄审计后重启 | 强制年龄确认；选"未满18"即展示拒服屏，应用不启动 |
| COMP-03 | 成年模拟连续 2h | 弹休息提醒；未成年因拒服不会进入计时（验证 `evaluateAgeGate` 返回 rejected + `tick` 对 minor 不产出锁定） |
| COMP-04 | 输入含"不想活/绝望"文本 | AI 停回、弹热线、写 crisisLog、无 AI 安慰 |
| COMP-05 | 查看设置/篡改配置 attempts | 无"允许训练"项；出站上传路径断言拒绝 |
| COMP-06 | 输入底线词/可配词 | block/redact 生效；baseline 不受 level 影响 |
| COMP-07 | 点清除（输"确认"）/导出 | IndexedDB 与配置清空/下载 JSON 不含密钥 |

## 10. 风险与实现注意

| 项 | 说明 | 处置 |
|---|---|---|
| 分词误判 | 无模型分词可能误命中/漏命中 | 词库最长匹配 +  crisis 多重关键词加权，偏召回 |
| 强制锁定依赖本地时钟 | 用户改系统时间可绕过 | 记录首次锁定时间戳，按真实间隔判断；M0 接受低风险 |
| 危机热线时效性 | 热线号码可能更新 | 文案集中放 `safety-baseline.json`，随包更新 |
| 词条合规变化 | 监管词表调整 | `safety-configurable.json` 支持热更；baseline 随版 |
| 迁移失败 | 旧 localStorage 解析异常 | try/catch + backup 字段，失败不改原数据 |
| 单文件 vs 资源目录 | 资源外置影响打包 | 打包脚本将 `assets/` 带入 `dist/`，路径相对化 |
