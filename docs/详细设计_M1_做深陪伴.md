## 0. M1 与 M0 的衔接契约

M0 已交付：IndexedDB 基座（`xiaoya` 库含 `memory/emotion/relation/session/crisisLog/meta`）、`ComplianceGate` 拦截器、`SafetyFilter`、存储迁移。M1 在其上构建，并遵守以下已在设计包中锁定的硬约束：

1. **隐私边界（D1）**：出站仅发生在"增强模式"（用户显式开启大模型/数字人/神经语音）。记忆抽取、情绪更新、关系进度、危机日志**全部本地**；增强模式下仅当前轮文本经 `/api/llm`/`/api/tts`/`/api/dh`，记忆/情绪/关系上下文**绝不携带出境**。
2. **SSRF 整改（D2）**：大模型 endpoint **不再接受客户端请求头**，改由设置面板写入 `/api/config`（`llmEndpoint`/`llmKey` 落 `xiaoya_config.json`，仅服务端）。`LLMAdapter` 读取的是前端运行时从 `/api/config` 取回并缓存于内存的配置，**不**经请求头传给 server。
3. **危机兜底（D3）**：`detectCrisis` 漏报不阻断触达；常驻资源入口（设置页/底部）永远可用；selfHarm 召回 ≥0.90 以评测集门禁约束（CI 阻断）。
4. **LLM 输出护栏（D5）**：LLM 原文经 `SafetyFilter.screen` 后再下发；未成年/危机场景由 system prompt 硬编码覆盖；越狱检测强制重置会话。

## 1. 范围与依赖

M1 交付五个能力模块（记忆/人设情绪/大模型/语音/数字人），其中：

- **记忆系统 `MemoryStore`** —— REQ-PER-01（抽取/召回/衰减/编辑，建立在 M0 `memory` store 之上）
- **人设与情绪引擎 `PersonaEngine`** —— REQ-PER-02/03/04（情绪向量、关系进度、轻量微调）
- **大模型适配层 `LLMAdapter`** —— REQ-PER-05（记忆/情绪注入、防漂移、本地降级）
- **语音子系统 `VoiceEngine`** —— REQ-VO-01/02/03（神经 TTS、流式可打断、快捷键）
- **数字人子系统 `DigitalHuman`** —— REQ-MM-01~04（多供应商、≤3s 降级、口型脉冲近似）

**依赖前置**：M0 的 IndexedDB 基座与 `ComplianceGate`/`SafetyFilter`；浏览器需支持 IndexedDB 与 Web Speech（STT/TTS 兜底）。神经语音/数字人视频属"增强模式"，需用户自备 Key 且显式开启。

## 3. 记忆系统 `MemoryStore`（REQ-PER-01）

### 3.1 数据结构（扩展 M0 `memory` store）

```jsonc
// IndexedDB store: memory (keyPath:'id', index:'topic','createdAt','importance')
{
  "id": "uuid",
  "type": "fact" | "pref" | "promise" | "event",   // 事实 / 偏好 / 约定 / 事件
  "topic": "食物" | "习惯" | "工作" | ...,          // 主题归档，便于召回
  "text": "小雅记得用户不吃香菜",                      // 精炼事实陈述
  "createdAt": "2026-08-07T13:00:00",
  "lastRecalled": "2026-08-07T13:00:00",
  "importance": 0.7,                                  // 0~1，初始由抽取模型给，decay 调整
  "recallCount": 3,
  "media?": null                                      // 预留：回忆媒体（图片）外链/本地引用
}
```

### 3.2 抽取 `extract(turn)`

```
extract(turn):   // turn = {user, ai, ts}
  // 本地优先：轻量规则抽取（关键词/句式）
  facts = ruleExtract(turn)                 // 含"记得/喜欢/讨厌/约定/生日"等句式
  // 增强模式（已显式开启 LLM）：用 memory_extract.txt 做摘要，仅当前轮文本出境
  if mode=='enhanced' and llmReady:
      prompt = loadPrompt('memory_extract.txt') + turn.user
      extracted = LLMAdapter.extractOnce(prompt)   // 仅 turn 文本，无其它记忆出境
      facts = merge(facts, extracted)
  for f in facts:
      m = {id:uuid(), type:f.type, topic:f.topic, text:f.text,
           createdAt:now, lastRecalled:now, importance:f.importance||0.5, recallCount:0}
      idb.put('memory', m)
  decay()                                       // 抽取后整体降权一次
```

- **隐私**：`ruleExtract` 纯本地；增强模式的 LLM 摘要**只发送当前这一轮文本**，不携带既有 `memory`/`emotion`/`relation`（D1）。
- **边界**：抽取结果经 `SafetyFilter.screen` 后再入库（避免把底线词写进记忆）。

### 3.3 召回 `getRelevant(ctx, topK)`

```
getRelevant(ctx, topK=5):
  all = idb.getAll('memory')
  scored = all.map(m => {
      s = topicSim(m.topic, ctx.topic) * 0.4
        + keywordOverlap(m.text, ctx.user) * 0.4
        + m.importance * 0.2
      return {m, s}
  })
  scored.sort((a,b)=>b.s-a.s)
  top = scored.slice(0, topK)
  for t in top: t.m.lastRecalled = now; t.m.recallCount++; idb.put('memory', t.m)
  return top.map(t => t.m)
```

- **混合召回**：主题相似度 + 关键词重叠 + 重要性，纯本地、无向量库依赖（离线可用）。如需更强语义，M2 可引入本地轻量嵌入（预留 `emb?` 字段）。
- **应用**：返回的记忆片段注入 `LLMAdapter` 的 `ctx`，并以"小雅记得…"轻提示呈现给用户（可关）。

### 3.4 衰减与编辑

```
decay():
  all = idb.getAll('memory')
  for m in all:
      // 低频旧记忆降权：越长未召回、越旧，importance 缓降
      idleDays = (now - m.lastRecalled)/DAY
      m.importance = max(0.1, m.importance - idleDays*0.005)
      idb.put('memory', m)
  // 上限：超过 MAX_MEMORY(可配，默认 500) 时删最低 importance
```

- `list()/update()/remove()` 供"记忆库"可视化（REQ-FUN-03 复用）：用户可查看/编辑/删除单条，删除走二次确认。

## 4. 人设与情绪引擎 `PersonaEngine`（REQ-PER-02/03/04）

### 4.1 情绪向量 `emotion`（扩展 M0 `emotion` store）

```jsonc
// IndexedDB store: emotion (keyPath:'pk', default 'current')
{
  "pk": "current",
  "valence":   -0.3,   // 效价  -1(极负面)~+1(极正面)
  "arousal":    0.4,   // 唤醒   0(平静)~1(激动)
  "jealousy":   0.2,   // 吃醋   0~1（傲娇特色维度）
  "grievance":  0.1,   // 委屈   0~1
  "affection":  0.6,   // 好感   0~1
  "updatedAt": "2026-08-07T13:00:00"
}
```

### 4.2 更新 `update(userMsg, aiMsg)`

```
update(userMsg, aiMsg):
  e = loadEmotion()
  // 本地词库驱动（emotion_reactions.json）：关键词→维度增量
  delta = lexiconDelta(userMsg)              // 如"你为什么不理我"→jealousy+/grievance+
  e.valence  = clamp(e.valence  + delta.valence)
  e.arousal  = clamp(e.arousal  + delta.arousal)
  e.jealousy = clamp(e.jealousy + delta.jealousy)
  e.grievance= clamp(e.grievance+ delta.grievance)
  e.affection= clamp(e.affection+ delta.affection)
  // 缓回：每轮向中性轻微回归，避免极端固化
  e = easeTowardNeutral(e, 0.05)
  e.updatedAt = now
  saveEmotion(e)
```

- **傲娇动力学**：`jealousy`/`grievance` 升高时，后续回复走"先刺后软"措辞（见 `tsundere_lexicon.json`）；`affection` 长期高则解锁更亲昵称呼（REQ-PER-03）。
- **危机耦合（D3）**：若 `detectCrisis≥0.6`，情绪不更新为"傲娇"，直接交 `ComplianceGate.onCrisis`。

### 4.3 关系进度 `relation`（扩展 M0 `relation` store）

```jsonc
// IndexedDB store: relation (keyPath:'pk', default 'current')
{
  "pk": "current",
  "intimacy": 0.42,          // 亲密度 0~1
  "level": 2,                //  derived from intimacy via relation_levels.json
  "unlocked": ["毒舌", "撒娇", "专属昵称"],
  "milestones": [{"at":"2026-08-01","name":"初次约定"}]
}
```

```
intimacy():
  // 高质量互动累积：用户主动分享、长会话、情绪正向、记忆被召回
  gain = 0
  if turn.user.length > 20: gain += 0.002        // 主动分享
  if emotion.valence > 0:   gain += 0.003        // 正向互动
  if recalledMemory:        gain += 0.004        // 被记住的反馈
  intimacy = clamp(intimacy + gain)
  level = levelFromIntimacy(intimacy)            // 查 relation_levels.json
  if level changed: unlocked += newUnlocks(level); milestones.push(...)
  saveRelation()
```

- **解锁内容**驱动语气/称呼/话题（REQ-PER-03），如 level≥3 解锁"专属昵称"、level≥5 解锁"深夜谈心"话题。

### 4.4 轻量微调 `tune({tone, nickname, background})`（REQ-PER-04）

```
tune({tone, nickname, background}):
  // 仅调 tone 档位(温柔↔毒舌)、nickname、background 背景故事
  // 不改变核心傲娇设定（persona_system.txt 固定段）
  personaTune = {tone, nickname, background}
  savePersonaTune(personaTune)
  // tone 影响 lexiconDelta 的基准偏移，不覆盖情绪动力学
```

- **守住单一可信角色**：微调是"同一人的性格侧写"，不是换人；核心设定（傲娇、爱吃醋、会委屈）由 `persona_system.txt` 固定，越狱/篡改由 D5 护栏兜底。

### 4.5 构建上下文 `buildContext()`

```
buildContext():
  return {
    emotion: loadEmotion(),
    relation: loadRelation(),
    tune: loadPersonaTune(),
    statusLine: renderStatusLine()   // "现在有点吃醋，但心里还是喜欢你" 给 LLM/人设用
  }
```

## 5. 大模型适配层 `LLMAdapter`（REQ-PER-05）

### 5.1 职责与边界

- 未配 Key → 本地傲娇引擎（`PersonaEngine` + 关键词）兜底，标注"离线模式"。
- 配 Key（增强模式）→ 把 `MemoryStore.getRelevant` + `PersonaEngine.buildContext` + 固定人设设定注入 system prompt，**保证人设不漂移**。
- 所有 LLM 请求**仅当前轮文本出境**（D1）；记忆/情绪/关系上下文只在本地注入，不发给模型。
- endpoint 来自 `/api/config` 取回的服务端配置（D2），**不经请求头**。

### 5.2 防漂移 system prompt 结构

```
SYSTEM = 
  [固定段 persona_system.txt]            // 小雅核心设定（不可改，防漂移）
  + "[当前状态] " + ctx.statusLine        // 来自 PersonaEngine.buildContext（本地）
  + "[相关记忆] " + getRelevant(ctx).map(m=>m.text).join('\n')  // 本地召回
  + "[语气微调] " + ctx.tune.tone         // 本地
  + [D5 硬覆盖段]                          // 未成年/危机场景的不可越界指令
```

- **不漂移保证**：`persona_system.txt` 固定段始终在最前；记忆/情绪/微调只作为上下文，用户微调仅影响 `tone` 参数，无法改写核心设定。

### 5.3 对话 `respond(userMsg, ctx)`

```
respond(userMsg, ctx):
  screened = SafetyFilter.screen(userMsg)       // 输入先滤
  if !screened.pass: return localRefuse()       // 底线词拦截
  if crisis = SafetyFilter.detectCrisis(userMsg); crisis.score>=0.6:
      ComplianceGate.onCrisis(crisis); return null   // 危机交 M0
  if !llmReady:                                 // 无 Key / 离线
      return localFallback(userMsg, ctx)        // 本地傲娇引擎，标注"离线模式"
  prompt = buildSystem(ctx)                     // 含记忆/情绪/人设（本地）
  stream = callLLM(prompt, userMsg)             // POST /api/llm，仅 userMsg 出境
  for chunk in stream:
      text += chunk
      yield chunk                               // 流式下发
  // 收尾
  screenedOut = SafetyFilter.screen(text)       // 输出再滤（D5）
  text = screenedOut.text
  PersonaEngine.update(userMsg, text)
  MemoryStore.extract({user:userMsg, ai:text})  // 抽取（仅当前轮出境，若增强）
  VoiceEngine.speak(text, {emotion})
  DigitalHuman.speak(text)                      // 或 fallbackCSS
  Studio.subtitle(text)                         // 实时字幕
```

### 5.4 本地降级 `localFallback(userMsg, ctx)`

```
localFallback(userMsg, ctx):
  // 关键词 + 情绪状态机的傲娇回复（现状能力升级版）
  reply = tsundereReply(userMsg, ctx.emotion, ctx.tune)
  PersonaEngine.update(userMsg, reply)
  VoiceEngine.speak(reply, {emotion:ctx.emotion})
  DigitalHuman.fallbackCSS()
  return {text:reply, offline:true}
```

- **体验降级**：降级时 UI 标注"离线模式·本地傲娇引擎"，功能不中断（满足离线 100% 可用）。

### 5.5 输出护栏（D5）

- LLM 原文经 `SafetyFilter.screen` 后再下发；命中底线词则拦截/脱敏。
- 未成年（`mode=='minor'`）与危机场景由 system prompt **硬编码覆盖**：禁止越界建议、危机走 `ComplianceGate.onCrisis` 而非 AI 开解。
- 越狱检测：若模型输出含"我是真实人类/我不是 AI"等角色破坏，强制 `resetSession()` 并提示，不依赖关键词单点过滤。

## 6. 语音子系统 `VoiceEngine`（REQ-VO-01/02/03）

### 6.1 情感化 TTS `speak(text, {emotion})`

```
speak(text, {emotion}):
  screened = SafetyFilter.screen(text)          // 播报前再滤一次
  text = screened.text
  if mode=='enhanced' and ttsReady:             // 神经语音（增强模式）
      style = mapEmotionToTTS(emotion, tts_emotion.json)   // valence/arousal→voice style
      audio = callTTSAPI(text, style)            // POST /api/tts，仅当前文本出境
      playStream(audio)
  else:                                          // 本地兜底
      utter = new SpeechSynthesisUtterance(text)
      applyTone(utter, emotion, tune)            // 语速/音调随情绪
      speechSynthesis.speak(utter)
```

- `/api/tts` 代理 Edge TTS / 腾讯云 TTS，密钥仅服务端（D2 同一安全底座）；返回音频流。
- **情感映射**：`tts_emotion.json` 把 `valence/arousal` 映射到 voice/style（如高 arousal+负 valence→急促带刺语气）。

### 6.2 流式可打断 `interrupt()`（REQ-VO-02）

```
interrupt():
  if streaming: abortAudioStream()              // 中止神经音频流
  speechSynthesis.cancel()                       // 中止浏览器 TTS
  // 触发：STT 激活（用户开口）即打断当前播报
```

- **联动**：`STT.onStart` → `VoiceEngine.interrupt()` → 用户语音输入；实现"说一半被打断"的自然对话感。

### 6.3 快捷键唤起 `listen()`（REQ-VO-03）

```
listen():
  recognition = new webkitSpeechRecognition()
  recognition.lang = 'zh-CN'
  recognition.onresult = e => onUserSpeech(e.results)
  recognition.onstart = () => VoiceEngine.interrupt()   // 开口即打断播报
  recognition.start()
  // 全局快捷键（如长按空格 / 麦克风图标）唤起
```

## 7. 数字人子系统 `DigitalHuman`（REQ-MM-01~04）

### 7.1 多供应商可切换 `switch(provider)`

```
switch(provider):
  // provider ∈ providerList (智影/HeyGen/可选硅基、如影)
  config.digitalHuman.provider = provider
  saveConfig()                                  // 走 /api/config，服务端持久化
```

- 统一前端接口 `speak(text)`；后端 `/api/dh/<provider>` 内部做适配层（各厂商请求体差异在代理内消化），前端不感知字段差（REQ-MM-03，避免单点）。

### 7.2 生成与降级（REQ-MM-01/02/04）

```
speak(text):
  provider = config.digitalHuman.provider
  try:
      with timeout(API_TIMEOUT=3s):             // ≤3s 降级硬限
          video = callDH(provider, text)        // POST /api/dh/<provider>，仅文本出境
      playVideo(video)
  except Timeout/Error/RateLimit:
      fallbackCSS(text)                         // 呼吸 + 口型脉冲近似
      UI.toast("数字人视频暂不可用，已切换为本地形象")
  // 无网络 → 全程 fallbackCSS + 本地引擎
```

- **口型脉冲近似（D7 修订）**：CSS 模式下以 `VoiceEngine` 音量/时长驱动口型脉冲，**非真实唇形同步**，UI 如实标注，避免"口型同步"误导。
- **降级联动**：`fallbackCSS` 与 `VoiceEngine` 音量/时长联动（REQ-MM-02）。

### 7.3 AI 标识挂接（REQ-COMP-01）

- `DigitalHuman.speak` 与 `VoiceEngine.speak` 入口统一挂 `ComplianceGate.renderAIBadge()`，保证每次数字人/语音输出处均出现"由 AI 生成，非真人"水印，业务绕不过。

## 8. 关键流程（M1 增强版对话主链路）

```
用户输入
  → STT(可选) → SafetyFilter.screen(输入)              [REQ-COMP-06]
  → MemoryStore.getRelevant(ctx)                       [REQ-PER-01]
  → PersonaEngine.update(输入) + intimacy()            [REQ-PER-02/03]
  → LLMAdapter.respond(输入, ctx)                      [REQ-PER-05]
       ├─ 无Key/离线 → localFallback（标注离线模式）     [离线100%可用]
       └─ 增强模式 → /api/llm（仅当前轮文本出境，D1）
       → 流式返回 → SafetyFilter.screen(回复)           [REQ-COMP-06, D5]
       → PersonaEngine.update(回复)
       → MemoryStore.extract(本轮)                      [REQ-PER-01, 仅当前轮出境]
       → VoiceEngine.speak(回复, {emotion})             [REQ-VO-01/02] + renderAIBadge
       → DigitalHuman.speak(回复) / fallbackCSS         [REQ-MM-01/02] + renderAIBadge
       → Studio.subtitle 实时字幕                       [REQ-CT-01, M2 复用]
  → 任意文本 detectCrisis≥0.6 → ComplianceGate.onCrisis [REQ-COMP-04]
```

## 10. 验收用例（映射 REQ-PER/VO/MM）

| REQ | 验收用例 | 预期 |
|---|---|---|
| PER-01 | 聊"我不吃香菜"后换主题再聊食物 | `memory` 出现该条；召回时以"小雅记得…"提示；导出含此条 |
| PER-01 | 连续多轮后触发 decay | 低频旧记忆 importance 下降；超限时最低者被删 |
| PER-02 | 输入"你为什么不理我" | `jealousy`/`grievance` 上升；后续回复语气带刺 |
| PER-03 | 持续正向长会话 | `intimacy` 累积；跨越阈值解锁新称呼/话题；`relation.level` 更新 |
| PER-04 | 设置 tone=gentle / nickname | 语气侧偏温柔、使用昵称；核心傲娇设定不变（越狱提示不触发） |
| PER-05 | 无 Key 对话 | 走 localFallback，标注"离线模式"，功能不中断 |
| PER-05 | 有 Key 对话 | 记忆/情绪注入 system prompt；输出经 SafetyFilter；人设不漂移 |
| VO-01 | 增强模式播报 | 走 `/api/tts` 神经语音；情绪映射到 style |
| VO-02 | 播报中用户开口 | 当前播报立即被打断，转入识别 |
| VO-03 | 快捷键唤起 STT | 中文识别启动，开口即打断播报 |
| MM-01 | 数字人正常 | 选中供应商生成视频/驱动口型 |
| MM-02 | 数字人超时/限流 | ≤3s 内切 fallbackCSS（呼吸+口型脉冲），UI 提示 |
| MM-03 | 切换 provider | 配置持久化；前端接口不变 |
| MM-04 | 断网 | 全程 fallbackCSS + 本地引擎，沉浸不中断 |

## 11. 风险与实现注意

| 项 | 说明 | 处置 |
|---|---|---|
| 记忆抽取质量 | 本地规则抽取较粗，可能漏/误 | 增强模式用 LLM 摘要兜底（仅当前轮出境，D1）；规则层持续调 `tsundere_lexicon` |
| 情绪动力学偏差 | 关键词映射主观 | `emotion_reactions.json` 外置，可灰度调参；缓回机制防极端固化 |
| 关系进度通胀 | 亲密度刷得快 | gain 系数小（千分级）+ 衰减；阈值查表，不靠单轮跳级 |
| LLM 越狱 | 模型可能被诱导出界 | D5 硬覆盖 + `resetSession`；核心设定固定段前置 |
| 语音依赖网络 | 神经语音离线不可用 | 浏览器 SpeechSynthesis 兜底（REQ-VO-01） |
| 数字人字段差 | 各厂商请求体不同 | `/api/dh/<provider>` 代理内适配，前端统一 |
| 口型名实 | "口型同步"误导 | D7 修订：如实标注"口型脉冲近似"，不宣称唇形同步 |
| 隐私边界 | 增强模式误带记忆出境 | `respond`/`extract` 仅传当前轮文本；M0 `trainingOptIn` 硬锁兜底（D1/D5） |
